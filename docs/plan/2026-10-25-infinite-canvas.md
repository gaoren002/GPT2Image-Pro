# 无限画布接入

入口：左侧「无限画布」，`/[locale]/dashboard/canvas`。

## 选型

- [Excalidraw](https://github.com/excalidraw/excalidraw)，锁定 `0.18.1`，MIT。图片排列、自由绘制、文字、形状、撤销与文件/图片导出直接使用其 React 编辑器。
- [React Flow / xyflow](https://github.com/xyflow/xyflow)，锁定 `12.12.0`，MIT。用于有类型端口、拖拽连线的图片节点工作流。
- [Jaaz](https://github.com/11cafe/jaaz) 作为 AI 创作画布的交互参考；它也使用 Excalidraw。没有复制其账号、模型调用、计费或服务端。
- tldraw 的生产使用需要额外许可证，本次没有引入。

两个编辑器仅在对应 Tab 打开时加载。Excalidraw 字体由 `prepare-canvas-assets.mjs` 在 dev/build 前复制到本站 public，Turbo 缓存同时保存该目录。

## 三种工作区

1. 图片工作台：从近期 36 张本人作品导入，或使用编辑器导入本机图片；排列、缩放、标注、导出选区/全图，再送到已有创作页做图生图。图库及历史的大图预览增加「加入画布」。
2. 节点工作流：提示词、参考图、生成节点；只执行用户点击的生成节点，按连接收集输入，结果可连到下一个生成节点。每次生成一张，复用站内生图/编辑 API 的原计费和退款规则，不自动运行整张图。
3. 自由白板：独立草稿，默认使用画笔；文字、箭头、形状、图片与文件导入导出复用 Excalidraw。

草稿按账号和 Tab 分开存储于 IndexedDB，每份最多 32 MiB。工作流另有限制：100 节点、300 连线、4 MiB JSON，不保存可执行函数。保存失败明确提示并在当前页面进程保留恢复副本；浏览器强制退出不能保证未落盘修改仍在，需导出文件备份。当前是个人工作区，没有跨设备同步或多人实时协作。

## 权限与执行

`canvas.listImages` 在 UOL 注册为无客户端参数的 protected 只读操作。服务端身份来自会话 principal，查询按本人、完成状态及非空主图过滤；对图片重新签名。

导入站内图片只接受 `/api/storage/` 安全相对地址，禁止跳转、限制正文与解码尺寸；导入后图片内嵌在本机草稿，不依赖旧签名。导出后用短期 blob 地址交给已有创作页，不把大图放入 sessionStorage。

工作流任务编号必须在付费请求前落盘。确认丢失保留编号并锁住重跑，提示查历史；不会自动重试。使用 Web Locks 限制同账号同时只有一个可编辑工作流会话，防止旧标签覆盖未知任务状态。不支持 Web Locks 的浏览器拒绝编辑工作流并提示更换浏览器。

## 发布

不需要数据库迁移。按既有 Web 发布流程构建并复制 public；保留 `public/excalidraw-assets/` 和字体文件。图像上游、Worker、sidecar 和计费政策无需更改。
