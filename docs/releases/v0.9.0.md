# GPT2Image Pro v0.9.0

本版将默认图片模型升级至 GPT Image 2.5，重建文本模型权限与 ChatGPT Web 模型映射，并集中改善 Web 生图的协议兼容、额度切换速度、计费展示和部署稳定性。

## 新增

- **GPT Image 2.5 成为默认图片模型**：新增 `gpt-image-2.5`、`gpt-image-2.5-sunburst` 和 `gpt-image-2.5-flare`；默认别名向 Images API 和 Responses 图像工具出站时解析为 Sunburst，同时保留 `gpt-image-2` 供兼容调用。
- **新增更高质量档位**：GPT Image 2.5 支持 `xhigh` 和 `max`，创作页及 Images、Chat Completions、Responses 等接口使用同一套参数校验。
- **更新文本主模型目录**：GPT-5.5 成为基础模型；Ultra 及以上套餐新增 GPT-6 Astra、GPT-5.6 Sol、GPT-5.6 Terra 和 GPT-5.6 Luna。具备相应接口权限但未解锁高级模型的用户仅可使用 GPT-5.5。
- **ChatGPT Web 主模型选择**：按实测的 Work 与 Images 模型目录映射主模型及推理强度，支持 GPT-5.5、GPT-6 Astra 和三款 GPT-5.6 模型。
- **Chat Completions 可使用 Images 上游**：自定义 API 和池 API 新增原生 Images 模式，可将适用的 Chat 请求转换为图片生成或编辑请求。
- **易支付套餐续购**：有效订阅可续购同一套餐，新周期积分发放和支付回调保持幂等。
- **积分包中文配置**：积分包支持中文名称和说明，购买页会按当前语言显示。
- **注册邮箱策略可配置**：后台可设置注册邮箱域名白名单，并可分别禁止 `+` 别名和邮箱本地部分中的点号。
- **管理员自助充值开关**：新增“管理员给自己充值”系统设置；关闭后普通管理员不能给自己充值，超管始终允许。

## 修复与改进

- **更快识别 Web 图片额度耗尽**：可从 SSE 和首次会话快照识别中英文额度终稿及图片工具限流，解析具体重置时间，将账号标记为 `limited` 后立即切换，常见额度失败由约 5 分钟缩短到数秒。
- **避免额度状态误判**：仅检查当前请求之后已经完成的 assistant 或 tool 结果；用户提示词、历史消息和 analysis 不参与判断。同一轮已经返回图片时优先采用图片。
- **减少无图请求重复等待**：候选图读取和兜底读取合并为一个轮询阶段，不再连续等待两个 120 秒窗口。
- **完善 Web 多候选图读取**：兼容批量 SSE、按轮次返回的会话消息、完整候选图和选择元数据，避免空终稿覆盖有效图片。
- **校准 ChatGPT Web 新协议**：同步最新 Sentinel prepare/finalize、PoW、Turnstile、workspace 请求头、会话信封、模型 slug、推理强度、历史续接和会话读取协议。
- **纯 Web 分组统一使用 2.5**：纯 ChatGPT Web 分组忽略客户端传入的图片版本，统一路由到 GPT Image 2.5；文本主模型仍按用户选择和套餐权限处理。
- **修复 Mixed 分组积分预估**：创作页按预测子组计算父组与子组的合成倍率，并与 Web-first 选路使用同一判定。
- **修复账单历史分页**：购买和订阅发放记录会在数据库分页前筛选，避免大量消费记录占满首屏。
- **完整执行图片分辨率校准**：启用分辨率校准后，轻微不足目标尺寸的成品使用轻量缩放，明显偏小的成品使用 Real-ESRGAN；Web 候选成品同样处理。
- **同步套餐与保存策略文案**：首页和购买页根据当前套餐能力、限制及图片保存策略动态生成说明。
- **统一界面体验**：补充统一动效、Skeleton、Button、Card 和 Tabs 规格，调整首页、创作页、设置、账单、Dashboard 及管理后台的布局与暗色主题表现，并支持减少动态效果偏好。
- **修复构建阻断**：修复全局样式层括号损坏、Skeleton 缺少工具函数导入及现有 Biome 阻断错误。

## 运维与性能

- **Real-ESRGAN 独立 Worker**：超分推理从 Next.js 进程迁移到独立 HTTP Worker，两个 Web 实例共享默认单并发队列，避免图片后处理占用页面和 API 进程。
- **补齐部署支持**：Docker Compose 已包含超分 Worker；源码或 systemd 部署提供独立服务模板、standalone 原生依赖链接及蓝绿发布步骤。Web 与 Worker 可通过相同的 `SUPER_RESOLUTION_WORKER_SECRET` 鉴权。
- **调整超分资源配置**：生产模板默认允许 24 个 ONNX 线程和 `CPUQuota=2400%`，可按服务器配置调整；Worker 失败时仍回退原图，不阻断生成。
- **图片维护任务全量收敛**：定时任务取消默认 500 条限制，单轮处理全部目标记录；显式指定 `limit` 的调用仍可限量。
- **无需数据库迁移**：本次升级没有新增或修改数据库迁移。
- **GHCR 命名空间迁移**：镜像发布地址随仓库迁移改为 `ghcr.io/gaoren002/*`；旧 `ghcr.io/meowfree/*` 镜像停留在既有版本。Docker Compose 用户升级前需获取本版 compose 文件或发布附件。

## 兼容性说明

- `gpt-image-2.5` 是默认简称；向 Images API 和 Responses 图像工具出站时会解析为 `gpt-image-2.5-sunburst`。纯 ChatGPT Web 路径使用 `picture_v2`，不发送图片型号字段。
- 纯 Web 主分组会把所有图片生成和编辑请求统一路由到 GPT Image 2.5，并忽略传入的图片型号及 `force_firefly`；Adobe 与 Mixed 分组沿用各自模型路由规则。
- 原能力键 `models.gpt55` 会兼容迁移到 `models.premium`，保留管理员此前配置的最低套餐门槛。
- 文本模型白名单已移除 GPT-5.4、GPT-5.4 Mini、GPT-5.2 及 GPT-5.3 Codex 系列。调用方应改用 GPT-5.5，或在具备旗舰权限时使用 GPT-6 Astra、GPT-5.6 Sol、Terra、Luna。
- Chat Completions 的 Images 上游模式适用于单轮、非 Agent、无历史记录的请求；多轮、Agent 和原样 Responses 请求继续使用对应上游。
