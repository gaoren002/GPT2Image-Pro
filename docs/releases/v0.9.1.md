# GPT2Image Pro v0.9.1

本版为审核提示词修剪增加 ChatGPT Web 回退。在 Codex/Responses
不可用时，系统会继续使用可用的 ChatGPT Web 账号修复提示词，避免单一
Responses 后端耗尽直接中断图片生成。

## 修复与改进

- **增加 Web 提示词修复回退**：审核拦截后仍优先使用 Codex/Responses
  或外接 `/responses`；初始没有可用 Responses 后端或运行时重试耗尽时，
  会跨组选择可用的 ChatGPT Web 账号继续修剪提示词。
- **隔离文字修复与图片额度**：Web 回退使用 GPT-5.5 低思考纯文本会话，
  不受图片生成额度限制，也不会清除或误减账号已有的图片额度与冷却状态。
- **更快切换异常账号**：Web 轮询遇到鉴权、限流或服务错误时立即结束当前
  尝试并换号；单个账号超时不会被错误标记为图片后端故障。

## 升级说明

- 本版本不包含数据库迁移。
- 提示词修剪的优先级保持不变：Codex/Responses 优先，ChatGPT Web 仅作为
  无可用账号或运行时重试耗尽后的回退。
- 本版本兼容 v0.9.0 的配置，无需新增环境变量或调整后端分组。
