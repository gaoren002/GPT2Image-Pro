# GPT2Image Pro v0.9.4

本版新增可选的「续费顺延积分有效期」系统设置，并修复透明图超分变黑底、
审核拒绝 SLA 误分类与生成记录偶发写入失败三个问题。

## 新增

- **续费顺延积分有效期（默认关闭）**：开启系统设置
  `CREDITS_RENEWAL_EXTENDS_EXPIRY` 后，Creem/Epay 续费发放周期积分成功时，
  把该用户未到期且到期日早于新周期末的订阅类批次统一顺延到新周期末。
  只延长不缩短、不追溯已过期、不影响积分包与免费积分，操作幂等。

## 修复

- **透明图超分变黑底**：超分前提取 alpha 通道，RGB 走原有 tile 管线，
  alpha 双三次插值放大后合成 4 通道 PNG；无 alpha 图行为不变。
- **审核拒绝 SLA 误分类**：「内容政策」「防护限制」中文拒绝话术纳入
  内容安全拒绝模式，不再计入平台故障。
- **生成记录写入失败降级**：generation INSERT 失败时用 compact 版本
  （截断 prompt、剥离大 metadata）重试一次，保证上游错误可追溯；
  扣费/退款链路不受影响。

## 升级说明

- 本版本不包含数据库迁移。
- 续费顺延为可选能力，默认关闭，需管理员在系统设置中开启。
